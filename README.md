# Text2Business AI Dispatcher

Демонстрационный вертикальный срез: свободный текст сервисной заявки преобразуется в проверенные факты, корпоративные данные, детерминированное решение и безопасный dry-run создания тикета.

## Быстрый запуск

Требуется Python `3.12.14`.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock
pip install --no-deps -e .
python -m text2business.cli
pytest
```

Docker:

```bash
docker build -t text2business-demo .
docker run --rm text2business-demo
```

## Что уже работает

Сценарий: «СеверФуд, склад на Дмитровском шоссе, 100. ХУ-18 не запускается после перезагрузки. Продукцию пока перенесли в соседнюю камеру. Нужен выезд специалиста».

Система:

1. Детерминированно извлекает клиента, адрес, оборудование, проблему и наличие резерва вместе с evidence.
2. Через типизированные mock-tools находит объект, оборудование, договор и открытые заявки.
3. Обычным кодом определяет приоритет и дедлайн SLA.
4. Формирует только dry-run создания тикета с `idempotency_key`, `expected_version` и обязательным подтверждением человека.
5. Возвращает проект ответа и последовательный trace.

LLM в этом срезе не используется. Корпоративные данные находятся в `src/text2business/data/corporate.json`. Реальных side effects нет.

## Границы

Это демонстрация, а не production-система. Пока не реализованы неоднозначный запрос, дедупликация повторного обращения, AI Gateway, Streamlit UI и полноценный календарь рабочих часов. Они добавляются следующими этапами.
